## Visão Geral

Esta atividade opcional da Unidade 3, Capítulo 2, consiste em explorar o ecossistema real de experimentação em Aprendizagem de Máquina através do Kaggle. O objetivo é analisar como problemas de Visão Computacional são formulados em contextos reais e relacionar os elementos observados com o pipeline de Aprendizagem de Máquina estudado.

## Objetivos

- **Identificação de Problemas**: Reconhecer como problemas de VC são formulados em contextos reais
- **Pipeline de ML**: Identificar elementos principais de um pipeline de aprendizado de máquina para imagens
- **Conexão Conceitual**: Relacionar descritores, modelos e estratégias com conceitos estudados
- **Reflexão Crítica**: Analisar diferentes abordagens para resolver o mesmo problema

## Estrutura da Atividade

### Passo 1 - Criar conta ou acessar o Kaggle

- Acessar: https://www.kaggle.com
- Criar conta gratuita se necessário
- Verificar competições em: https://mlcontests.com/

### Passo 2 - Encontrar um problema de Visão Computacional

Procurar por:
- Uma competição
- Uma discussão
- Um notebook

Relacionado a tarefas como:
- Classificação de imagens
- Detecção de objetos
- Segmentação de imagens
- Reconhecimento facial
- Análise médica por imagens

### Passo 3 - Analisar o conteúdo encontrado

**1. Definição do problema**
- Qual é a tarefa (classificação, detecção ou segmentação)
- Quais são as classes previstas
- Qual é o objetivo da competição ou discussão

**2. Dataset utilizado**
- Origem do dataset
- Número de imagens
- Número de classes
- Formato das imagens
- Possíveis desafios do dataset

**3. Pipeline de aprendizado de máquina**
- Pré-processamento das imagens
- Extração de características
- Modelos utilizados
- Estratégias de treinamento

Relacionar com pipeline: imagem → representação → classificador → rótulo

**4. Algoritmos utilizados**
- Verificar se algoritmos clássicos são utilizados (SVM, Random Forest, KNN)
- Contexto de uso
- Discussão sobre motivos para não utilização

**5. Avaliação do modelo**
- Métricas utilizadas pelos participantes
- Função de score da competição
- Relação com métricas estudadas
